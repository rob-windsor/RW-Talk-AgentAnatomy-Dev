# The Anatomy of an AI Agent - for Developers

An AI agent is more than a language model responding to a prompt. Instructions define its purpose, knowledge provides information, tools extend its capabilities, and orchestration coordinates the process. But how do these components fit together, and what role does each play?

In this session, we'll examine the major components of an AI agent, what each contributes, and how they interact. Using C# and Microsoft Agent Framework, we'll progressively build a conference travel agent, starting with instructions and adding organizational knowledge, business tools, reusable skills, and external capabilities through Model Context Protocol (MCP).

Along the way, we'll explore how agents retrieve information, maintain conversation context, invoke tools, and coordinate their activities. You'll leave with a practical understanding of how the pieces fit together and a foundation for building your own AI agents.
